# 🇪🇺 Capitales de Europa

**Aprende las capitales de 30 países europeos**

## Características

- 🗺️ **Modo Mapa**: Explora Europa con banderas posicionadas, filtro por región, mini-juego "¡Encuéntralo!"
- 📚 **Modo Aprender**: Tarjetas con capital, población, idioma, moneda y dato curioso
- 🧠 **Modo Quiz**: 12 preguntas con 3 tipos (país→capital, capital→país, bandera→país)
- ⚡ **Modo Desafío**: 60 segundos para responder la mayor cantidad

## Datos

- **Total países**: 30
- **Regiones**: Nórdicos, Occidental, Central, Sur, Este
- **Datos por país**: bandera, capital, población, idioma, moneda, dato curioso

## Paleta de Colores

- Primary: `#003399` (azul europeo)
- Secondary: `#1a5276`
- Accent: `#0e6655`

## Uso

```jsx
import CapitalesEuropa from "./games/capitales-europa";

<Route path="/capitales-europa" element={<CapitalesEuropa />} />
```
